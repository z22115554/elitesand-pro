萬聖節美術素材插槽
==================

把 <插槽名>.webp 放進這個資料夾就會自動換成美術圖，不用改程式；缺的插槽維持 CSS／SVG 保底畫法。
server 的 /assets/halloween/manifest.json 會列出這裡有哪些 .webp，前端只載入清單上的插槽。

格式：WebP、透明背景（recap-bg 除外）、sRGB。檔名只能用小寫英文、數字與連字號。
尺寸是建議值（已含 2 倍或最大縮放的解析度），長寬比請盡量照填，圖片一律以 contain 置中顯示。

OBS 南瓜燈疊加層（/halloween）
  pumpkin-unlit   600×600   南瓜燈「未點亮」。
  pumpkin-lit     600×600   南瓜燈「全亮」。必須跟 unlit 同尺寸、同構圖、同位置，進度會由下往上露出這張。
  tag-candy       280×340   糖果名牌（斗內最低檔）。中央留約 60% 寬的空白放名字與金額，掛繩點在上緣正中央。
  tag-ghost       280×340   幽靈名牌。同上。
  tag-bat         280×340   蝙蝠名牌。同上。
  tag-pumpkin     280×340   南瓜名牌。同上。
  tag-witch       280×340   魔女帽名牌（最高檔）。同上。
  bat             256×128   繞著南瓜飛的小蝙蝠，翅膀張開、朝右。
  ghost-prank     700×800   頻道點數「搗蛋」時衝過畫面的大幽靈。
  pop-candy       128×128   聊天 !treat 彈出的糖果小圖示。
  pop-ghost       128×128   聊天 !trick 彈出的幽靈小圖示。

歌詞模板「萬聖燭光」（/display）
  lyric-ghost     400×460   長間奏時飄出來的小幽靈。

歌單外觀「萬聖夜」（/setlist）
  setlist-pumpkin 256×256   「正在播放」卡片右側的南瓜燈（亮著的）。
  setlist-web     360×360   左上角的蜘蛛網，網的起點在圖片左上角。會蓋在「正在播放」卡片上，線條請細、半透明。
  setlist-bat     256×144   右下角的小蝙蝠，翅膀張開。

控制面板
  panel-badge     96×96     開啟萬聖節主題時，側欄 Logo 角落的小徽章。
  recap-bg        1920×1080 活動回顧卡背景（不需透明）。上緣有標題、左下會疊點亮的南瓜燈、右半邊壓暗放統計，
                            請畫氛圍場景（夜空、月亮、墓園或城堡剪影），不要放會被蓋住的主角。
