萬聖節美術素材插槽
==================

把 <插槽名>.webp 放進這個資料夾就會自動換成美術圖，不用改程式；缺的插槽維持 CSS／SVG 保底畫法。
server 的 /assets/halloween/manifest.json 會列出這裡有哪些 .webp，前端只載入清單上的插槽。

格式：WebP、透明背景（recap-bg 除外）、sRGB。檔名只能用小寫英文、數字與連字號。
尺寸是建議值（已含 2 倍或最大縮放的解析度），長寬比請盡量照填，圖片一律以 contain 置中顯示。

                            液體由程式從後面畫進去；換圖時鍋口位置要跟這個一致。
  potion-candy    240×320   熬出的藥水瓶：糖漿（甜蜜藥水）。

  potion-witch    240×320   藥水瓶：黑貓的毛。
  （名牌高一律 340，寬依圖：糖果、蝙蝠、南瓜的中段加寬過，中央空白要能放一行五個字。
    掛環／南瓜蒂必須在上緣正中央，程式依圖量出洞的高度讓繩子穿過去；換圖後要重量。）

  setlist-pumpkin 256×256   「正在播放」卡片右側的南瓜燈（亮著的）。
  setlist-web     360×360   左上角的蜘蛛網，網的起點在圖片左上角。會蓋在「正在播放」卡片上，線條請細、半透明。

控制面板
  panel-badge     96×96     開啟萬聖節主題時，側欄 Logo 角落的小徽章。
  recap-bg        1920×1080 活動回顧卡背景（不需透明）。上緣有標題、左下會疊大鍋與熬出的藥水、右半邊壓暗放統計，
                            請畫氛圍場景（夜空、月亮、墓園或城堡剪影），不要放會被蓋住的主角。
